# Luna's Kitty — Cat Care Game

## What This Is
Virtual cat care game for Luna (3yo). Feed, pet, play, brush, nap.

## Stack
- Single `index.html`, no dependencies
- localStorage for state persistence

## URLs
- **Live:** http://192.168.68.73:3457
- **Port:** 3457

## Design
- Pink/pastel aesthetic — Luna loves pink and cats
- Big touch targets for iPad (she's 3)
- Heart meters for needs system
- Keep it SIMPLE — toddler-proof UI

## Gotchas
- Single-file app, no build step
- Must work on iPad Safari (touch-first, no hover states)
